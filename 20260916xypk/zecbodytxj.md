# 贵州省人民医院成功实施“自体左半肝肝移植联合肝后段下腔静脉人工血管置换术”

> 更新时间：2026-09-16 (UTC+8)

2021年3月18日，在麻醉科、ICU、心外科、血管外科、医学影像科等多学科团队的密切配合下，贵州省人民医院肝移植团队独立为1例原发性下腔静脉平滑肌肉瘤患者，成功实施“自体左半肝肝移植联合肝后段下腔静脉人工血管置换术”。即将病变的下腔静脉及肝脏整块切除，用人工血管重建下腔静脉，在体外去除病变的下腔静脉及右肝后，把患者自己剩下的完好的左肝重新移植回体内。

患者王XX，女，39岁，因“发现双下肢肿胀2周”入院。患者入院前已辗转多家医院求治，均表示无法手术。入院后经增强CT及MRI检查，诊断考虑为“下腔静脉内肿瘤性病变（III型）并肝右静脉侵犯，病变下端达左肾静脉开口水平，病变下部右侧突破血管壁累及右肾上腺及右肾筋膜，病变上端距右心房6mm。考虑原发性平滑肌肉瘤可能性大”。

因该患者病情复杂，在医务处主导下组织包括肝胆外科、麻醉科、ICU、心外科、血管外科等多学科讨论，意见为：患者诊断“下腔静脉内肿瘤性病变”明确，无远处转移，具有手术指征；但手术难度很大。手术难度具体为：1.由于下腔静脉是人体最大的血管，血流量很大，用人工血管替代病变的血管，手术中大出血的风险高。2.同时该患者病变涉及肝后段下腔静脉，术中需要重新将肝静脉缝合至置换的人工血管上，手术难度大，估计该手术过程需要1-2小时；而常温下肝脏血流阻断的安全时限为15分钟，极限时间20-30分钟。3.担心在手术过程中，如阻断下腔静脉后中途开放血流可能因血管内压力的急剧变化导致下腔静脉内病变脱落，引起急性肺栓塞而危及患者生命。如手术中采用体外循环将下半身的血流转入心脏，虽可以降低肺栓塞的风险，但由于抗凝药物如肝素的使用，会增加术中大出血的风险。4.术前影像学提示右肝静脉侵犯，需同时行右肝后叶切除的可能性很大；CT解读患者左半肝体积713.63ml，占全肝体积的41.89%。

因此，综合考虑后，决定为该患者实施“左半肝自体肝移植联合肝后段下腔静脉人工血管置换术”。 手术过程顺利，历时9小时，未采用静脉转流。术后患者康复顺利，2周后出院，现状况良好。术后病理报告为“下腔静脉平滑肌肉瘤，约8cm X 6cm X 4cm大小，浸润下腔静脉壁全层”。

检阅文献，目前国内外仅有3篇文献报道（最早2015年）采用自体全肝移植治疗下腔静脉血管平滑肌肉瘤，而采用自体半肝肝移植联合下腔静脉置换术治疗下腔静脉血管平滑肌肉瘤未见报道。目前我院已常规独立开展包括儿童肝移植、劈裂式肝移植、成人亲属活体半肝移植等复杂肝移植手术，已成功完成肝移植手术150余例，近2年每年完成肝移植手术近50例，成功率大于90%，居省内领先！  

                         

在治疗过程中，医院高度重视，多次组织麻醉科、心外科、血管外科、医学影像科等学科团队对患者进行多会诊，第一时间确立治疗方案，为救治患者赢得了“黄金期”。4月8日，患者带着书有“手术精湛 医德高尚”牌匾，感谢贵州省人民医院医务人员的崇高医德。
